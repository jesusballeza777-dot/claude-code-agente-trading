# Registro de decisiones de arquitectura (ADR)

Cada decisión de arquitectura va en un ADR (`NNN-titulo.md`: contexto, decisión, alternativas, consecuencias), según CLAUDE.md.
Un ADR solo pasa a **Aceptado** con la aprobación explícita del propietario. Los límites del motor de riesgo solo cambian mediante un ADR aceptado (CLAUDE.md, regla 4).
